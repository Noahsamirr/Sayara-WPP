# Sayara - Car Insurance Website

A modern, responsive car insurance website for Saudi Arabia with bilingual support (English/Arabic).

## Features

- 🌐 **Bilingual Support**: English and Arabic language switching
- 📱 **Fully Responsive**: Works on all devices (mobile, tablet, desktop)
- ⚡ **Fast Loading**: Optimized for performance and Core Web Vitals
- 🎨 **Modern UI**: Clean and professional design
- 📋 **Insurance Plans**: Compare Basic, Standard, and Premium plans
- 📝 **Contact Form**: Get instant quotes
- ❓ **FAQ Section**: Common questions answered
- 🔍 **SEO Optimized**: Structured data and meta tags

## Project Structure

```
Sayara-WPP/
├── index.html          # Main HTML file
├── styles.css          # Stylesheet
├── script.js           # JavaScript functionality
├── robots.txt          # Search engine directives
├── sitemap.xml         # Site structure for search engines
└── llms.txt            # LLM information file
```

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- No frameworks required (pure static site)

## Getting Started

1. Clone this repository:
```bash
git clone https://github.com/yourusername/Sayara-WPP.git
cd Sayara-WPP
```

2. Open `index.html` in your web browser or use a local server:
```bash
# Using Python
python -m http.server 8000

# Using Node.js (if you have http-server installed)
npx http-server
```

3. Visit `http://localhost:8000` in your browser
